# v0.4.0 — Agent recovery and broader source workflows

- Per-claim check explanations and bounded recovery guidance in the package and skill.
- Connected headings, caption/table relationships and neighboring evidence.
- Explicit-version collection BM25 search, optional source-heading indexing,
  process index reuse and separately scoped cross-source checks.
- Offline doctor with repair guidance.
- Exact multi-step arithmetic, percentages and explicit linear/count normalization.
- Opt-in local OCR for pages without native text; explicit image handoff to a
  caller's visual model, preserving unverified interpretation status.
- Inspector claim decisions and imported calculation receipts with source links.
- Natural-PDF retrieval probes and matched three-arm agent evaluation records.

[Usage, payloads and boundaries](../agent_improvements.md)

This remains a local alpha. Grounding-v1 and its thresholds are unchanged.
No general accuracy improvement, complete conflict audit, native visual verifier,
human-reviewed natural-document benchmark or per-page incremental parser is claimed.
