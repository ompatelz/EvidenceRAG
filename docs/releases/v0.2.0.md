# EvidenceRAG v0.2.0

EvidenceRAG is a local, single-user toolkit for retrieving evidence from technical
PDFs, tracing it to original pages/regions, and checking agent-written answers.

## Included

- Python SDK and JSON CLI for ingestion, document discovery/status, BM25/dense/
  hybrid/reranked search, bounded page context, source anchors and draft checks.
- Optional local stdio MCP server with eight tools and confined PDF ingestion.
- Companion agent skill, available both inside the wheel and as a separate archive.
- Web inspector and optional Codex, OpenRouter and OpenAI answer adapters.
- Reproducible fixtures, reviewed retrieval labels, raw evaluations and CI checks.
- Wheel/source distributions, a standalone skill archive, release provenance and
  SHA-256 checksums. Application license: AGPL-3.0-only; owned fixtures: CC0.

## Install

Install the wheel from this release with `python -m pip install PATH_TO_WHEEL`.
For optional MCP transport also install `mcp==1.30.0`. Run `evidence-rag --help`.
To export the skill: `evidence-rag export-skill ./evidence-rag-agent`.

See docs/agent_integration.md in the source distribution for all interfaces and
model-cache setup. Core installation and BM25 need no API key or model weights.
The SDK and MCP tools never call a generation provider; the agent supplies drafts.

## Scope

This is an alpha release for a trusted local process on loopback. OCR, pixel-level
chart/diagram interpretation, shared-host authentication, distributed ingestion
and arbitrary-document accuracy guarantees are outside this release. Missing
semantic verification withholds natural-language answers. Support models can
still reject supported drafts. Small synthetic diagnostics and exploratory agent
trials do not establish improved accuracy over other agents or RAG systems.

The package is distributed through GitHub Releases, not PyPI. No cloud service,
paid generation, telemetry account or automatic personal-skill installation is
required. Source and runtime dependencies remain subject to their license terms.
