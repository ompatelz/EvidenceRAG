# v0.5.0 — Enforced recovery sessions and retrieval visibility

- Add process-local SDK/MCP recovery sessions with fixed question/version scope,
  two search attempts, one closing recheck and immutable event receipts.
- Count failed search execution, reject unobserved evidence IDs and prevent
  repeated starts from resetting an existing session's budget.
- Add optional page diversity over a bounded BM25 candidate pool, keeping original
  scores and canonical evidence text.
- Expose collection candidate rankings, selection/packing decisions, exclusions,
  coverage and truncation.
- Expand pinned natural-PDF development probes with matched candidate-pool
  variants and inspectable CI summaries. No accuracy improvement is claimed.

[Usage and boundaries](../recovery_sessions.md)

Sessions require a long-lived trusted engine process and do not enforce a global
budget across processes, stateless tools or document scopes. Grounding-v1 remains
unchanged; the caller still supplies drafts and decides whether new evidence
justifies a correction.
