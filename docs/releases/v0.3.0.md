# EvidenceRAG v0.3.0

This release adds source-backed exact arithmetic to the local agent toolkit:

- `EvidenceRAG.calculate` in Python.
- `evidence-rag calculate` with a bounded JSON request.
- `calculate_evidence`, the ninth stdio MCP tool.
- Companion-skill guidance for using calculations without bypassing grounding.

Two cited quantities come from explicit table cells or a unique textual quantity
with an explicit unit. Arithmetic uses fractions and returns source contexts,
page/region anchors, unit information and an optional expected-result comparison.
It rejects ambiguous extraction, truncated sources, mixed-unit addition/subtraction,
zero division and unsupported numeric formats. No LLM or model weights are required.

Every receipt reports claim_support=not_assessed. A correct calculation does not
prove that an operation answers the question or that an account is eligible for
a policy. Natural-language draft checks, policy thresholds and held-out results
are unchanged. Semantic false abstention remains a known limitation.

The existing library-loans development fixture reproduces 21 + 14 = 35 days
across two source pages; an expected result of 34 is explicitly rejected. This
is a deterministic capability check, not a new accuracy benchmark. Regression
controls cover misleading number formats, ambiguity and non-bypass of grounding.

See docs/source_calculations.md for payloads and boundaries. The wheel, source
archive, standalone skill archive, provenance manifest and SHA256SUMS are included.
Application license: AGPL-3.0-only. Existing local-only scope and unsupported OCR,
pixel interpretation, multi-tenancy and distributed ingestion limits still apply.
